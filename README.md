Entry for make.fun `tiny-chess-01`: the strongest chess engine in 4 KB of Python.
https://make.fun/bounty/tiny-chess-01

`main.py` (3,222 bytes, Python 3.13 stdlib only) plays chess with 0x88 board,
negamax alpha-beta + quiescence, transposition table and fixed 60,000
nodes/move. Deterministic, no model calls. Practice Elo mean 1,424.
